## 🚀 Getting Started

To explore or run the code locally, follow these quick steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to a specific assignment folder (e.g., C++ Day 1):**
   ```bash
   cd CDAC_Assignment_Acts/CPP/assignment/day1
   ```
3. **Compile and Run (For C++ files):**
   ```bash
   g++ main.cpp -o program
   ./program
   ```
