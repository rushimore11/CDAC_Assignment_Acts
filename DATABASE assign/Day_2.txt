Assignment 3

Solve the queries using emp, dept and salgrade table (fetching data from multiple tables
without joins)

1.Write a query to display empno, ename, deptno, dname, loc, sal, salgrade for all employees working as managers. 

SELECT 
    e.empno,
    e.ename,
    e.deptno,
    d.dname,
    d.loc,
    e.sal,
    s.grade AS salgrade
FROM 
    emp e,
    dept d,
    salgrade s
WHERE 
    e.deptno = d.deptno
    AND e.sal BETWEEN s.losal AND s.hisal
    AND UPPER(e.job) = 'MANAGER';
	
2. Write a query to display empno, ename, deptno, dname, loc, sal, salgrade for all employees joined in the year 1981.  
SELECT 
    e.empno,
    e.ename,
    e.deptno,
    d.dname,
    d.loc,
    e.sal,
    s.grade AS salgrade
FROM 
    emp e,
    dept d,
    salgrade s
WHERE 
    e.deptno = d.deptno
    AND e.sal BETWEEN s.losal AND s.hisal
    AND YEAR(e.hiredate) = 1981;
	
3.Display empno, ename, deptno, dname, sal, salgrade for all employees joined on Tuesday.  
Dayofweek(curdate())----will give day 1:Sunday, 2:Monday etc
SELECT 
    e.empno,
    e.ename,
    e.deptno,
    d.dname,
    e.sal,
    s.grade AS salgrade
FROM 
    emp e,
    dept d,
    salgrade s
WHERE 
    e.deptno = d.deptno
    AND e.sal BETWEEN s.losal AND s.hisal
    AND DAYOFWEEK(e.hiredate) = 3;
	
	
4. Write a query to display empno, ename, deptno, dname, loc, sal, salgrade for all employees joined in the year 1981 and earning no commission. 
SELECT 
    e.empno,
    e.ename,
    e.deptno,
    d.dname,
    d.loc,
    e.sal,
    s.grade AS salgrade
FROM 
    emp e,
    dept d,
    salgrade s
WHERE 
    e.deptno = d.deptno
    AND e.sal BETWEEN s.losal AND s.hisal
    AND YEAR(e.hiredate) = 1981
    AND (e.comm IS NULL OR e.comm = 0);
